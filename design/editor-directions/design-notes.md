# 页息编辑器视觉方向 · 第 01 轮

日期：2026-10-06。范围：正式 React + Tiptap 编辑页的视觉方向探索，不修改正式应用代码。

## 品类与任务

- 品类：单作者 Markdown / MDX 写作工作台。
- 首屏主角：当前文稿的标题与正文；作者来到页面后第一件事是继续写，而不是查看管理信息。
- 主要约束：编辑区居中，不再常驻右侧说明卡片；延续页息纸面、Logo 与《PageHush 字体执行规范》。
- 标杆参照：iA Writer 的无干扰纸面、Ulysses 的 Library / Editor 分离、Typora 的即时排版、Bear 的轻量管理入口。取舍是保留“正文优先”和轻入口，不做通用笔记软件的密集侧栏。

## 方向

| 方向 | 意图 | 适合场景 | 风险 |
| --- | --- | --- | --- |
| 素纸长卷 | 深化现有纸面语言，正文像排在一张连续长纸上 | 默认方向，最稳 | 需要控制装饰密度 |
| 呼吸白页 | 更白、更空、更轻，让界面几乎消失 | 长时间专注写作 | 品牌记忆弱于其他方案 |
| 文学刊物 | 用刊头、页边信息和编辑排版建立仪式感 | 更强品牌识别与内容感 | 装饰元素过多会干扰写作 |
| 暮色书房 | 暖黑夜间模式，不是通用开发器黑 | 夜间写作与后续主题能力 | 与现有亮色纸面差异最大 |

## 推荐

首选 **素纸长卷**：它保留当前品牌资产与纸面基调，同时补足篇号、稿件元信息、当前行反馈和沉底工具栏，能在不干扰写作的前提下明显提升完成度。

若希望产品更有“个人刊物”气质，选 **文学刊物**；若写作时长优先，选 **呼吸白页**；若夜间写作是高频场景，选 **暮色书房**。
