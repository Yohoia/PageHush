# Markdown 写作页 · 第一轮方向探索

交付日期：2026 年 10 月 6 日。当前阶段是可操作的写作页设计小样，方向尚待用户选择；推荐 01「纸间」。

## 任务与范围

- 用户：每天长时间写随笔、文章和个人笔记的人。
- 核心对象：一篇 Markdown 笔记，以标题、正文、所属分组和保存状态识别。
- 主动作：打开笔记 → 连续写作 → 检查文章结构或预览 → 保存 → 继续写。
- 主要设备：桌面；手机提供单列写作、笔记目录和预览切换。
- 当前交付：三套代表性写作页、同屏对比工具、设计说明及截图证据。
- 无需配图：文字本身是主要内容；摄影或插画会挤占写作空间。

## 品类与标杆

品类是长期使用的文档创作工具。参考 iA Writer 的编辑器、文件库与预览关系，以及 Bear 对字号、行高、行宽的可调节思路。

来源：[iA Writer 界面导览](https://ia.net/writer/how-to/quick-tour)、[实际查看的编辑器截图](https://static.ia.net/2024/09/WriterEditorPane.webp)、[Bear 字体与排版设置](https://bear.app/faq/typography-options/)。这些参考用于质量基线与任务关系，不用于精准还原。

对已查看的 iA Writer 编辑器截图作以下拆解：

| 可观察的要素 | 对写作任务的意义 | 本项目取舍 |
| --- | --- | --- |
| 文档内容占最大的连续区域 | 用户每天主要面对正文 | 三方案都让正文成为主角 |
| 目录显示名称、节选和日期 | 找到上次写到的文档 | 纸间保留名称与日期，减少节选造成的重复 |
| 文件位置与文档列表分开 | 文件管理与编辑有不同层级 | 纸间合并小型笔记库，不复制完整文件系统 |
| 正文为等宽文字 | Markdown 标记和文本保持直接联系 | 独页沿用；纸间改用宋体连续阅读 |
| 工具位于窗口边缘 | 将管理动作从正文中移开 | 使用顶栏、边栏或底部小工具条 |
| 库的灰色表面与编辑器区分 | 余光中辨认工作区边界 | 纸间用不同底色分区，校样用细分隔线 |
| 标题沿用 Markdown 文本规则 | 写作者不需要学习另一套结构 | 独页、校样保留原文标题标记；纸间呈现排版后的章节 |
| 目录可隐藏，预览可按需显示 | 创作与整理的注意力需求不同 | 三方案分别展示专注与预览状态 |

## 方向卡

### 01 纸间 · 推荐

| 字段 | 决定 |
| --- | --- |
| 北极星 | 翻开一本常用的笔记本；正文在注意力中心，笔记与大纲位于余光里。 |
| 调性 | 安静、精致、中等密度、轻、庄重。依据是长时间中文文章写作；工具安静，文字有完整的节奏。 |
| 生成引擎 | 中文书页的正文与目录关系，来自用户的阅读和写作习惯。 |
| 首屏骨架 | 246px 笔记目录 → 居中正文 → 130px 文章大纲；顶部一行工具。目录默认四篇，正文约 36 个汉字一行。 |
| 页面结构 | 目录固定；文档是主要滚动区；专注时收起目录与大纲，正文重新居中。 |
| 各区块形式 | 目录用平面列表；标题直接长在纸面上；正文用段落、章节与引文；大纲是无容器的文本导航。 |
| 字体 | Songti SC / STSong 标题 37px、正文 18px / 1.95；苹方 12–14px 用于工具和列表。 |
| 色彩 | #fbfaf7 正文底、#efeee8 目录底、#343a35 墨色、#4b6555 选中与操作。 |
| 主视觉 | 中文宋体的段落、字形与疏密关系；不用主视觉图片。 |
| 图标 | 功能字符为主；品牌使用一个「纸」字小印框，不为列表加装饰图标。 |
| 控件语法 | 5px 小圆角、浅绿灰选中底、极轻分隔；按下缩至 .97，聚焦显示绿环。 |
| 动效 | 纸页落定：正文首次 450ms 出场；操作即时按下反馈；专注状态在 320ms 内收起侧栏。 |
| 结构性突破 | 通过内容重排进入单列专注，辅助面板从同一工作区退场，保留当前文档。 |
| 记忆点 | 专注按钮让正文留在画面上、两侧目录消失；整页由阅读与管理状态切回连续写作。 |
| 放弃什么 | 营销口号、装饰性配图、顶部格式工具堆、永久双栏预览。 |

推荐理由：正文可直接编辑，也可以切换到 Markdown 原文；笔记定位和长文大纲无需打断写作。比独页更方便日常笔记管理，比校样占用更少的界面注意力。

### 02 独页

| 字段 | 决定 |
| --- | --- |
| 北极星 | 夜里只亮着的一张书桌；把连续输入留在同一个窄列中。 |
| 调性 | 安静、精致、稀疏、中等分量、偏严肃；强调保持输入连续，不强调管理。 |
| 生成引擎 | 独处写作的场景，翻译为隐藏文件管理、正文窄列与贴边工具。 |
| 首屏骨架 | 82px 顶栏 → 最大 690px 单列纯文本 → 74px 底部视图与字数；无常驻侧栏。 |
| 页面结构 | 正文单独滚动；笔记从顶栏唤出一个短列表；写作与预览共用同一列。 |
| 各区块形式 | 顶部以文档索引导航；正文保留 Markdown 语法；底栏直接提供视图、字数和保存状态。 |
| 字体 | Menlo 等宽与苹方混排，32px 标题、18px / 2.15 正文；工具 12px。 |
| 色彩 | #242329 灰紫底、#dedce1 文字、#bcb0d3 状态与专注强调，不使用荧光或发光。 |
| 主视觉 | 独立的一列文本和大面积连续背景；没有卡片和图片。 |
| 图标 | 方括号用于小字标，其余用名称和文档序号。 |
| 控件语法 | 4px 圆角与灰紫表面；状态短促显现；写作/预览用一块滑动底板切换。 |
| 动效 | 字段首先出场；底栏选中底板 200ms 横移；笔记菜单 180ms 展开；操作按下有回应。 |
| 结构性突破 | 文件管理退出主工作区，整页只围绕当前文本组织；导航位于顶栏和浮层。 |
| 记忆点 | 底部字数刻度随输入增长；没有将刻度包装为独立指标卡。 |
| 放弃什么 | 常驻目录、文章大纲、格式工具条、并排预览。 |

取舍：最适合连续输入，打开或整理多个文档需要多一步。

### 03 校样

| 字段 | 决定 |
| --- | --- |
| 北极星 | 编辑的校对桌；原文和读者看到的页面同时在场。 |
| 调性 | 安静、精确、密集、轻、严肃；服务文章结构与排版检查。 |
| 生成引擎 | 校对的双稿工作方式，强调输入与结果的对照关系。 |
| 首屏骨架 | 68px 窄导航轨 → 顶部文档与视图动作 → 等宽原文、排版预览并排 → 保存状态底栏。 |
| 页面结构 | 原文与预览因对照任务各自滚动；可展开原文或预览；手机改为切换，不强行分屏。 |
| 各区块形式 | 管理入口压缩为导航轨；原文是完整纯文本；右侧是白色出版排版；状态落在工作区边缘。 |
| 字体 | Menlo 15px / 2 原文，苹方 17px / 1.85 正文与 32px 标题。 |
| 色彩 | #f6f6f4 工作台、#ffffff 阅读面、#292a2c 文本、#a94d38 小面积身份强调。 |
| 主视觉 | 两份内容在不同密度下的对应；黑白稿面与严格分隔，不使用图片。 |
| 图标 | ¶、＋、▤ 和中文功能名；控制数量，不给每篇文档加图标。 |
| 控件语法 | 2px 方正圆角、单线边框；保存为黑色实心动作；原文/分屏/预览直接切换。 |
| 动效 | 输入立即影响阅读稿；面板宽度 300ms 变化；阅读稿首次 350ms 轻出场；操作按下有反馈。 |
| 结构性突破 | 以原稿与阅读稿的关系作为主结构，文件管理退为按需展开的窄面板。 |
| 记忆点 | 输入一个 Markdown 标题，在旁边马上看到排版后的章节。 |
| 放弃什么 | 宋体正文、生活场景文案、常驻宽文件列表、手机上的并排对照。 |

取舍：整理复杂文章更直接；写作界面占比和控件数量高于另外两种方向。

## 差异检查

三套共享笔记内容，不共享页面布局或样式。纸间用列表导航与排版编辑，独页用顶栏导航与窄列原文，校样用导航轨与双稿对照。工作区骨架、对象呈现、导航位置和密度均有区别，不是简单换明暗主题。

## 已实现与边界

- 三套均可修改标题和正文、切换笔记、新建笔记、搜索、预览、进入专注及保存。
- 纸间增加分组筛选与文章大纲定位，排版编辑可以转回 Markdown 原文。
- 校样有实时预览，并支持独立展开原文或预览。手机隐藏分屏选项，保持单列阅读。
- 本轮使用虚构的四篇笔记内容；未接入账号、云同步、协作、发布或附件。
- Markdown 是用于方向验证的小型解析器，覆盖标题、段落、粗体、斜体、行内代码、列表和引文；不是完整 CommonMark / GFM 编辑器。
- 独立页面的保存使用浏览器存储；对比页中的编辑与保存按工具规则使用临时内存，关闭后不持久化。
- 最终方向尚未定稿，完整产品开发、生产级编辑器行为和后端不在这一轮探索范围内。

## 验证与评审记录

本轮为方向探索。依据 skill 的流程，先交付对比页供用户选择；没有启动独立视觉评分，未独立评审，不提供虚构分数。

主 Agent 已实际查看三套 1280×900 与 390×844 截图，并检查纸间的 2× 细节。修正了窄屏时主区落入零宽网格列的问题，以及校样在对比页内被误初始化为单列的问题。默认页的最终检查没有控制台错误、横向溢出或图片加载错误。

交互走查：

1. 纸间修改 Markdown → 预览确认粗体 → 保存 → 重新加载读取正文，恢复验证通过；验证用文字随后恢复。
2. 纸间切换到第二篇笔记，标题与正文一起变化。
3. 校样输入新章节，右侧立即出现对应标题；验证后恢复原文。
4. 独页打开笔记列表 → 搜索「雨停」→ 打开结果 → 预览显示对应章节。
5. 专注进入与退出留有帧序列及开始、中间、结束图；本机没有 ffmpeg，所以未导出视频。

没有项目类型检查或 lint 配置；本轮没有运行生产构建或全量测试。对比工具自身的截图报告只有自动请求 favicon.ico 的 404，不影响候选页面或选择工具。

减法记录：删去「文字，慢慢来。」「每一个细节，都值得被写下。」「留一页给自己」等不帮助操作的短句；删除未实现的搜索快捷键标签、无实际排序动作的箭头，以及与视觉换行不对应的行号。
