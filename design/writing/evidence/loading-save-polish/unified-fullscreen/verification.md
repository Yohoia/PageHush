# 顶部操作栏与文章发布、删除验证

采用现有纸张配色和图标样式。编辑工具和返回、保存、删除、全屏操作共用固定顶部栏，背景与页面一致，没有边框，初始没有阴影，滚动超过 8px 后出现轻微阴影。宽屏同一行，左右使用对称空间保持工具栏居中；窄屏操作按钮同一行，工具栏第二行。文档预留栏高度，查找与下拉浮层位于栏上方。详情页隐藏滚动条，仍可正常滚动。

全屏仅改变文档显示范围。工具栏始终保留、保持位置和透明度；分类、封面、元数据和标签保留原有 DOM，以 CSS 网格高度与透明度同步过渡，标题同步调整字号和间距，统一使用 460ms 时长与同一缓动曲线。正文不做整体淡出，快速切换直接反向过渡。减少动态效果时直接切换。未新增确认完成按钮。

发布由卡片右下角箭头触发，成功显示顶部“文章当前已发布”提示，并在原按钮显示对勾。1.8 秒后同一按钮切换成撤回发布图标，点击后恢复草稿并显示“文章已撤回发布”。状态只用于 PageHush。文章链接与发布按钮是独立的兄弟元素，发布点击阻止默认动作和冒泡。详情页删除图标直接位于右上角，删除确认后调用软删除接口，成功回到列表。保存保留发布状态。

## 验证

- 真实 API：三轮创建临时草稿、发布、保持已发布保存、撤回发布、删除以及读回，全部通过；临时文章已从列表移除。
- 独立本地接口样本：三轮卡片发布与撤回、刷新读回，点击发布不跳转，链接内没有嵌套按钮。最终另测三轮延时图标转换，均依次显示 Check、Undo2，并保持列表 URL。见 timed-publication-checks.json。
- 页面提交失败验证：保存失败保留标题与正文，重试后读回正确且保持已发布；删除失败保留确认框，重试后返回空列表。
- 发布成功对勾与撤回入口实际截图：publish-check.jpg、withdraw-icon.jpg。
- 宽屏与窄屏按钮水平对齐、工具栏居中；真实文章滚动后顶部仍固定：fixed-header-final.jpg、fixed-header-scrolled.jpg。
- 最终三轮全屏切换：正文透明度始终为 1，进入时正文图片没有向下跳动，封面、分类、标签最终高度为 0；退出后恢复原有高度，工具栏始终位于顶部。完整样本见 collapse-checks.json。
- 快速双击与 Esc 退出：均恢复正常视图，正文透明度为 1；顶部背景、边框、阴影与滚动条计算样式见 final-header-checks.json。
- 类型检查、lint 与 diff 空白检查通过。未运行生产构建或全量测试，未做独立视觉评分。
