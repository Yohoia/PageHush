# 页息设置页视觉与功能方向 · 第 01 轮

日期：2026-10-06。范围：设置页方向探索与功能结构小样，不修改正式设置页。

## 任务与结构

设置页需要同时服务两类任务：

1. **当前分类 / 分类与标签**
   - 当前分类名称、博客 `topic` 映射、默认语言、默认标签。
   - 引用数量、未发布修改数量、首页可见性。
   - 分类创建、重命名、合并、迁移、隐藏与删除前迁移。
   - 标签去重、整理和移除，避免悬空关联。
   - 重命名不改变既有文章 URL。

2. **项目与后端**
   - PostgreSQL 服务器连接与诊断。
   - MinIO Bucket、凭据脱敏摘要与签名访问检查。
   - PageHush API / Worker 状态。
   - Astro 博客源码版本、内容包与构建配置。
   - 发布检查、Nginx 切换、失败保留旧版本与回滚。
   - 数据库与资源备份、恢复演练。
   - 密钥只保存在服务端，不进入前端状态。

## 方向

| 方向       | 结构                                          | 适合场景                   | 风险                             |
| ---------- | --------------------------------------------- | -------------------------- | -------------------------------- |
| 双栏控制台 | 左侧设置导航，右侧分组卡片                    | 默认设置页；功能会持续增加 | 需要控制卡片数量                 |
| 分段卡片   | 顶部「当前分类 / 项目服务」分段，卡片顺序展开 | 移动端和功能逐步接入       | 层级比双栏少，后期可能拥挤       |
| 纸面档案   | 左侧分类账，右侧系统档案                      | 强化页息刊物气质           | 运维信息密度较高时不如控制台直观 |
| 运维状态台 | 先服务指标，再发布流水线                      | 服务器接入与部署排障       | 与当前亮色纸面差异最大           |

## 推荐

首选 **双栏控制台**。它能把「当前分类」和「项目服务」明确分开，同时为 PostgreSQL、MinIO、Astro、Worker、备份和发布回滚留出可扩展导航；视觉上仍使用当前亮色纸面和轻量卡片。

次选 **分段卡片**，适合先做最小可用版本；**纸面档案**适合品牌表达优先；**运维状态台**适合后续作为服务器诊断视图或暗色工作台模式。

## 动效

- 页面标题与内容块交错入场。
- 卡片或行悬停轻微上浮 / 背景变化。
- 服务状态点轻微呼吸，提示待连接。
- 所有候选支持 `prefers-reduced-motion: reduce`。
- 动效只使用透明度和 transform，不干扰表单操作。
