# 页息文稿页视觉与动效方向 · 第 01 轮

日期：2026-10-06。范围：文稿目录页方向探索与可交互小样，不修改正式应用页面。

## 品类与任务

- 品类：单作者写作工作台的文稿库。
- 用户任务：找回旧文、继续写作、判断草稿 / 已发布 / 有修改状态、快速筛选标题与标签。
- 首屏主角：文章标题与状态；管理控件服务找回，不抢过内容。
- 标杆取舍：参考 Ulysses 的 Library / Editor 分离、Bear 的轻量标签与搜索、Notion 的清晰状态反馈。保留搜索、状态筛选、标题先行的地板结构；避免通用后台表格和密集侧栏。

## 方向

| 方向     | 体验意图                             | 动效                                   | 适合场景                 | 风险                   |
| -------- | ------------------------------------ | -------------------------------------- | ------------------------ | ---------------------- |
| 纸面目录 | 延续当前呼吸白页，让文稿库像安静索引 | 行入场、标题轻微右移、页边线扫过       | 文章数量多、默认方向     | 视觉差异较温和         |
| 页息刊物 | 把文稿库办成一本连续刊物             | 左栏入场、分隔线生长、悬停展开页边红线 | 强化个人品牌与内容仪式感 | 装饰密度需要控制       |
| 字卡书架 | 用首字和标题生成轻量视觉卡           | 卡片交错入场、悬停上浮、底部线扫动     | 按标题浏览、内容较少时   | 文章很多时视觉负担较高 |
| 时间归档 | 以月份与时间线组织写作痕迹           | 时间线生长、条目横向入场、悬停右移     | 回看写作历程和最近修改   | 状态检索弱于列表       |

## 推荐

首选 **纸面目录**。它与已选的“呼吸白页”编辑器最连贯，能承载大量文章、状态和筛选，动效也最克制。

次选 **页息刊物**，适合在空状态、欢迎文稿或品牌展示页引入刊物感；若个人品牌表达优先，也可以升级为默认文稿页。

**字卡书架**适合作为内容较少时或未来封面 / 系列文章的补充视图；**时间归档**更适合作为“按时间查看”的辅助视图，不建议直接替代默认列表。

## 动效规则

- 入场：80–700ms，行 / 卡片按 35ms 递进，不循环播放。
- 悬停：120–250ms，位移不超过 6px，只使用透明度和 transform。
- 筛选：结果重新入场，空状态原地说明原因。
- 搜索：输入即筛选，保留查询和清除入口。
- 全部候选支持 `prefers-reduced-motion: reduce`，减弱动态效果时直接呈现最终状态。
